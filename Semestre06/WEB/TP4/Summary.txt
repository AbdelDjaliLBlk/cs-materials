OBJECTIF GÉNÉRAL
----------------
Ce TP couvre les concepts avancés du développement web côté serveur
en PHP : manipulation de chaînes/tableaux, upload de fichiers,
programmation orientée objet (POO), gestion des sessions et cookies,
et interaction avec une base de données MySQL.


EXERCICE 1 - Exploration des fonctions PHP
------------------------------------------
- Analyser et commenter un script PHP utilisant des fonctions de
  manipulation de chaînes et de tableaux.
- Fonctions abordées :
    * strrev()       → inverse une chaîne
    * ucfirst()      → met la première lettre en majuscule
    * str_pad()      → complète une chaîne à une longueur donnée
    * str_repeat()   → répète une chaîne N fois
    * explode()      → découpe une chaîne en tableau
    * array_unique() → supprime les doublons d'un tableau
    * array_filter() → filtre les éléments d'un tableau
    * array_map()    → applique une fonction à chaque élément
    * json_encode()  → convertit un tableau en JSON
    * json_decode()  → convertit un JSON en tableau PHP

EXERCICE 3 - POO : Classe abstraite, Interface, Héritage, Exceptions
--------------------------------------------------------------------
Créer un système de gestion d'un garage automobile avec :

- Classe abstraite Voiture :
    * Propriétés protégées : $marque, $modele, $annee
    * Méthode getDescription() → retourne la description
    * Méthode abstraite rouler() (sans implémentation)

- Interface Rechargeable :
    * Méthode recharger()

- Classes dérivées :
    * Essence    → implémente rouler() (moteur à essence)
    * Electrique → implémente rouler() + recharger() (Rechargeable)
    * Hybride    → implémente rouler() + recharger() (Rechargeable)

- Classe Garage :
    * Propriété privée $voitures (tableau)
    * ajouterVoiture() avec vérification instanceof + exception
    * afficherVoitures() appelle rouler() pour chaque voiture

- Gestion d'exceptions :
    * Tester l'ajout d'un objet invalide
    * Capturer l'exception avec try...catch et afficher le message

EXERCICE 6 - Recherche d'utilisateurs dans une base de données
--------------------------------------------------------------
- Créer la base de données et la table :

    CREATE DATABASE IF NOT EXISTS biblio;
    USE biblio;
    CREATE TABLE utilisateurs (
        id      INT AUTO_INCREMENT PRIMARY KEY,
        nom     VARCHAR(255) NOT NULL,
        email   VARCHAR(255) NOT NULL UNIQUE,
        adresse VARCHAR(255)
    ) ENGINE=InnoDB DEFAULT CHARSET=utf8;

- Développer un script PHP de recherche/filtrage :
    * Filtrer les utilisateurs par nom, adresse ou email
    * Afficher les résultats dans un tableau HTML
    * Utiliser des requêtes SQL paramétrées (PDO ou mysqli)
